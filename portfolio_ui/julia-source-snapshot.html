Run it live

You need Julia and Pluto.jl. From the repo root:

using Pluto
Pluto.run(notebook="notebook.jl")

Note. This page is a static snapshot. The notebook is interactive: sliders for profit rate, market yield, maturity and face value, a structure picker, and editable auction rates. The snapshot shows the notebook's default values.
